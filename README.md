# 📋 Descripcion.
Aplicacion de consola desarrollada en kotlin   donde se podra registrar alumnos, listar, buscar,eliminar mostrar alumnos aprobados y suspensos.
El sistema utiliza una lista mutable de alumnos donde es una data class  que contiene nombre , apellido y nota  el mismo alumno se valida asi mismo utilizando el bloque init y require para la validacion. La clase GestorListaAlumno implementa 
una interfaz  GestorFuncionesAlumnos. 

# 🎯 Objetivo.
- El objetivo de este proyecto es masterizar las listas mutable 
- Mejorar las validaciones respecto a anteriores proyectos
- Reutilizar codigo que cubra con tareas repititidas
